## 🚀 Getting Started

Welcome to the kontext-engine! This application helps you manage context for AI agents effectively. Instead of feeding your AI agent the entire codebase, you can use kontext-engine to provide the right context with ease.

### 🖥️ System Requirements

- Operating System: Windows 10 or later, MacOS Mojave or later
- RAM: Minimum 4 GB
- Disk Space: At least 200 MB available
- Internet connection for downloading the application

### ⚙️ How to Use kontext-engine

1. **Open the Application**: 
   Find kontext-engine in your applications list and double-click to launch it.

2. **Add Your Code Context**:
   - Click on the "Add Context" button.
   - Input the necessary code snippets or descriptions that provide context for your AI.

3. **Save Your Context**: 
   After you enter the context, click the "Save" button. This allows your AI to access the context when needed.

4. **Run Your AI Agent**: 
   Once you have saved the context, your AI agent can utilize the relevant information without needing the entire codebase.

### 🔧 Features

- **User-Friendly Interface**: Designed for individuals without programming experience.
- **Quick Context Management**: Easily add, remove, and update contextual information.
- **Search Functionality**: Quickly find specific context entries using the search bar.
- **Support for Multiple File Types**: Upload not just code snippets, but also documents and images for improved context.
